# Ranking tracker — target queries → our URLs

How organic traffic actually arrives, in four stages:
**Discovered (sitemap) → Indexed (queue) → Ranked (per query) → Clicked.**
We are at stage 2→3. This tracker maps each money query to the page that
must win it, so progress is measured per query, not by vibes.

Routine (weekly, ~10 min):
1. GSC → Performance → Queries tab: note any new query with impressions.
2. GSC → Pages: watch Indexed count climb (17 → target 40+ by mid-Dec).
3. Incognito google.com check for 3–4 queries below; record position
   (or "not ranked yet"). Log the date + position in the table.
4. Never search your own site while logged into Google accounts tied to
   AdSense/GSC admin for "checking ads" — incognito, positions only.

Competitors observed (Nov 2026) for signature queries: signaturepng.com
(2022), toolsimpli.com, pngmaker.com — established domains with dedicated
landing pages + FAQ/SoftwareApplication schema (same playbook as ours;
they just have years of trust). Expect long-tail wins first, head terms
in months.
